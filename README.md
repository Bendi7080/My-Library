# My Library ✦

Персональная библиотека фильмов, сериалов и книг.

- 📁 Папки и вложенные папки
- 🎬 Фильмы и сериалы
- 📚 Книги
- ⏳ Статусы и прогресс
- ❤️ Избранное
- 🔎 Поиск
- 📊 Статистика
- 🌙 Светлая/тёмная тема
- 🎨 Акцентный цвет
- 💾 localStorage
- 📦 JSON экспорт/импорт
- 📱 Адаптация под iPad и телефон

## Структура
```text
my-library/
├── index.html
├── style.css
├── script.js
├── manifest.webmanifest
├── sw.js
├── README.md
└── assets/
```

Данные хранятся локально в браузере. Для резервной копии используй экспорт JSON.
